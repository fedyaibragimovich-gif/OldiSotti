# OldiSotdi marketplace audit — 14 September 2026

Scope: authentication UI, listings/upload, search, sharing, favorites/history, conversations, notifications, moderation, browser storage, offline cache, public branding, build output. Payment implementation and support assistant excluded.

## Findings addressed

- Listing-card shares used unsupported hash links; now use the listing query parameter.
- Posting form preserved a success screen on reopening; mount a fresh form for a new posting session.
- Image processing could race submission; serialize image processing, validate JPEG/PNG/WebP, disable the form during processing/saving.
- Validate phone, title and description before uploading; stop inventing seller response time/rating for new listings.
- Category changes retained incompatible subcategory/brand filters; clear dependent filters.
- Honor incoming q/lang links and set the document language.
- Feed spinner used an arbitrary 280 ms delay; bind loading/error state to the actual subscription.
- Put load-more control below results.
- Guard repeated chat opening and auth submissions; keep Google popup inside direct user activation.
- Clear private conversations/notifications before account changes and reject stale callbacks.
- Clear drafts/error feedback on chat changes and prevent an old send completion from modifying a different chat.
- Mark incoming messages read while their conversation is open.
- Initialize the seller's unread counter for a new conversation.
- Remove the duplicate notification widget and use explicit events for chat/listing navigation.
- Mark-all-read also clears unread conversation counters.
- Reports with absent optional fields failed Firestore serialization; omit undefined fields.
- Stop storing moderation reports in browser storage.
- Validate listing shape and report status/length in Firestore; reject unread-counter tampering, forged message fields and conversations targeting unpublished listings.
- Decode remote listing documents defensively to prevent malformed records from crashing the feed.
- Synchronize personal blocked sellers from Firebase per account, remove per-card database reads and shared-account block caches.
- Persist moderation/settings before showing success; propagate deletion errors to the initiating UI.
- Delete listing documents before photos so failed document deletion cannot destroy a live ad's photos. Cleanup failures are logged; orphan cleanup still needs an operational retry mechanism.
- Disable production sample-data overwrite/reset; resync now reloads actual data.
- Remove fabricated price-history graphs. Price bookmarking copy explicitly says local-only and no automatic alerts.
- Clipboard success follows actual successful copying.
- VIP/similar feeds show active listings only.
- Restore map attribution.
- Remove whole-document mutation observer and fix known legacy Telegram channel links directly.
- Display OldiSotdi branding; domain and GitHub repository identifiers are unchanged.
- Offline asset misses no longer return HTML; avoid caching API/error responses and bound asset cache.
- Write server bundle/source map outside the public Vercel output directory.

## Validation

GitHub CI is the execution gate: Firestore emulator rules, browser-storage tests, listing decoding, service-worker regressions, support API regression tests, TypeScript and production build.
First patch passed all gates. Final revision results must be read from PR #7 / its CI run.

## Limits and remaining work

The execution environment and interactive browser were unavailable. No claim of complete A–Z/end-to-end verification is made:
- Google/email login, password reset, two real accounts exchanging messages, upload on Android/iOS, keyboard/screen-reader and visual layouts require live verification.
- Firebase authorized domains and new custom-domain ownership/DNS have not been verified or changed.
- Listing/chat/notification queries currently read all matching documents before client filtering/sorting. Server pagination/search and cursor-based notifications are a scalability follow-up.
- Conversation messages remain embedded in a Firestore document; migrate to paged message documents before approaching the document-size limit.
- Stored external photo availability, existing seller claims/demo content and all old malformed data have not been manually reviewed or deleted.
- Price history and price-drop delivery are not implemented; the UI no longer represents them as working.
- No existing listing, report, account or conversation was created/deleted for production testing.
- Payment and support bot behavior remain outside this audit.
